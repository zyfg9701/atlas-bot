# P3.5 runbook - real gateway (scheme B: Agent CLI)

> **主路径起法已收敛到 [`cli-primary-runbook.md`](./cli-primary-runbook.md)**（一键脚本、探测、旁路表、PC 顺序）。本页保留 P3.5 实现细节与冒烟。


Baseline: main @ 68bc202. Scheme B CLI adapter. Optional A OpenAI-compat. Reject C vendor grok.

## What changed

- CliAgentGateway sendPrompt spawns ATLAS_AGENT_CLI with -p print mode (non-echo)
- atlas-bot-gateway binary listens 127.0.0.1:8787 /invoke /healthz /stats
- Hub: unset ATLAS_GATEWAY_URL keeps InMemoryGateway; set URL uses HTTP client
- hub:turn_finished in-process via TurnFinishedHint; HTTP remote Hub emits after sync-complete sendPrompt
- OpenAI only when ATLAS_GATEWAY_BACKEND=openai
- Cold status/roster/offbox never wake gateway

## Env

- ATLAS_HUB_BIND default 127.0.0.1:7700
- ATLAS_GATEWAY_URL unset=stub set=HttpGatewayClient
- ATLAS_GATEWAY_HTTP_BIND default 127.0.0.1:8787
- ATLAS_GATEWAY_BACKEND cli|openai|stub
- ATLAS_AGENT_CLI default agent
- ATLAS_AGENT_CLI_EXTRA_ARGS JSON array
- ATLAS_AGENT_CLI_TIMEOUT_MS optional
- ATLAS_OPENAI_BASE_URL ATLAS_OPENAI_API_KEY ATLAS_OPENAI_MODEL

## Start

1. Start package atlas-bot-gateway with ATLAS_AGENT_CLI pointing at tools/mock-cli/mock-atlas-agent-cli.sh (or real agent) and ATLAS_GATEWAY_BACKEND=cli
2. Health: HTTP GET /healthz and /stats on 127.0.0.1:8787
3. Start package atlas-bot-hub with ATLAS_GATEWAY_URL=http://127.0.0.1:8787
4. PC client under clients/pc
5. Stub-only: leave ATLAS_GATEWAY_URL unset when starting hub

## Smoke

Run hub integration test p35_smoke with nocapture and test-threads=1.
Expect line: SMOKE_OK p35 cli-gateway non-echo+dual-agent+cold+interrupt+http-turn_finished

Also keep green: p3_smoke, atlas-bot-gateway and atlas-bot-hub unit tests, xai-tool-protocol bot_relay_conformance, tools/license-check/check.sh, clients/pc unit tests.

## Known limitations (acceptance section 9)

1. Interrupt: kills spawned CLI child via start_kill; returns hadActiveRun+killed; never fake success when idle. OpenAI fallback cancels in-flight HTTP.
2. Turn finished: in-process bridge OR Hub emits after sync-complete HTTP sendPrompt (hubEmitTurnFinished).
3. CLI: real Cursor agent requires login; CI uses tools/mock-cli mock script; override ATLAS_AGENT_CLI.

## Out of scope

IdP, mobile, VNC, vendor grok runtime, CLI product mainline, mcp-adapter, installers.
